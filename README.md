# Eevlice Palimpsest

## How do I install these formulae?

`brew install eevlice/palimpsest/<formula>`

Or `brew tap eevlice/palimpsest` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "eevlice/palimpsest"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
